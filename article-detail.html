Vite构建工具使用指南

Vite 构建工具 前端工程化

Vite 是一种新型前端构建工具，能够显著提升前端开发体验。它主要由两部分组成：

  • 一个开发服务器，它基于原生 ES 模块提供了丰富的内建功能，如速度快到惊人的模块热更新（HMR）。
  • 一套构建指令，它使用 Rollup 打包你的代码，并且它是预配置的，可输出用于生产环境的高度优化过的静态资源。

为什么选择 Vite

传统的构建工具如 Webpack 在开发环境下需要先打包所有代码，随着项目规模增大，启动时间和热更新时间都会显著增加。Vite 解决了这个问题：

Vite 利用浏览器原生的 ES 模块支持，在开发环境下无需打包，直接按需加载模块，从而实现秒级的启动速度和即时的热更新。

安装 Vite

使用 npm 或 yarn 安装 Vite 非常简单：


# npm
npm create vite@latest

# yarn
yarn create vite

# pnpm
pnpm create vite

创建项目

创建项目时，你可以选择不同的框架模板：


# 创建名为 my-vite-project 的项目
npm create vite@latest my-vite-project -- --template react-ts

项目结构

一个典型的 Vite 项目结构如下：


├── node_modules/
├── public/
├── src/
│   ├── assets/
│   ├── components/
│   ├── App.vue
│   └── main.js
├── .gitignore
├── index.html
├── package.json
└── vite.config.js

核心配置

在 vite.config.js 中可以配置 Vite 的各种选项：


import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

// https://vitejs.dev/config/
export default defineConfig({
  plugins: [react()],
  server: {
    port: 3000,
    open: true,
    proxy: {
      '/api': {
        target: 'http://localhost:8080',
        changeOrigin: true,
        rewrite: (path) => path.replace(/^\/api/, '')
      }
    }
  },
  build: {
    outDir: 'dist',
    sourcemap: false
  }
})

常用命令

  1. 开发环境启动：npm run dev
  2. 构建生产版本：npm run build
  3. 预览生产构建：npm run preview

总结

Vite 凭借其极速的开发体验和现代化的构建方式，已经成为越来越多前端开发者的首选工具。它不仅大幅提升了开发效率，还提供了丰富的插件生态和灵活的配置选项，满足不同项目的需求。
